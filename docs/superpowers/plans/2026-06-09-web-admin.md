# 管理后台实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 KnowMate 实现一个简洁、实用、接入真实后端 API 的管理后台。

**Architecture:** 创建独立 `web-admin` Vite React + TypeScript 应用，通过 Vite proxy 调用 GoFrame API。后端只补齐管理后台缺失的读接口，包括文章列表、推文详情和 MCP 调用日志列表，复用现有任务、反馈、画像、推荐解释和健康接口。

**Tech Stack:** GoFrame HTTP handler/store、MySQL、React、TypeScript、Vite、Vitest、Testing Library、Playwright。

---

## File Structure

- Modify: `goframe-backend/internal/model/model.go`
  - 增加文章和 MCP 日志筛选模型。
- Modify: `goframe-backend/internal/store/mysql.go`
  - 增加 `ListArticles`、`PostByID`、`ListMcpCallLogs` 查询。
- Modify: `goframe-backend/internal/handler/handler.go`
  - 注册 `GET /articles`、`GET /posts/{post_uid}`、`GET /mcp-call-logs`。
- Modify: `goframe-backend/internal/handler/handler_test.go`
  - 先写失败测试覆盖新增接口。
- Create: `web-admin/`
  - Vite React TypeScript 管理后台、API client、页面组件、样式、测试和 Playwright 配置。
